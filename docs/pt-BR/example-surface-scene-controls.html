    scene.controls: Controle de informações da cena

    Adicione um botão funcional que leia a cena da montagem e mostre dimensões e grade no modal nativo.

    O que você vai construir

    Adicione um botão funcional que leia a cena da montagem e mostre dimensões e grade no modal nativo.

    Superfície: scene.controls · Modo: augment · Gravewright 0.3.0 / SDK 1.x.

    Quando monta e quem pode usar

    Selecione uma cena e clique em Informações da cena. A montagem fornece sceneId, width, height e grid. maps.get verifica o nome da cena visível; não muda a seleção.

    O dono instala o ZIP local em Módulos → Instalar módulo → Instalar por ZIP. Depois, o mestre ativa a versão na lista de extensões da mesa. O exemplo não pede permissões adicionais nem obtém um handle global; todas as leituras usam o api fornecido pela montagem. Mestre e jogador recebem somente os dados autorizados pelo servidor. Streamers não recebem esta montagem autenticada.

    Baixe o pacote completo

    Baixar ZIP dos fontes · manifest.json · main.mjs · styles.css · LICENSE.txt

    Salve os quatro arquivos na mesma pasta. Compacte o conteúdo da pasta, com manifest.json diretamente na raiz do ZIP. Não inclua uma pasta extra, estado local ou chaves privadas. O upload local é uma decisão de confiança do dono; para distribuição por catálogo, use o fluxo de assinatura da referência de módulos.

    main.mjs

    javascript
    // Original documentation example. License: MIT. Target: Gravewright 0.3.0, SDK 1.x.
export default {
  start({ api, styles }) {
    styles.use("styles.css");
    api.i18n.register({
      "en": {
        "Scene information": "Scene information",
        "Close": "Close",
        "Grid": "Grid",
        "Refresh": "Refresh",
        "Loading…": "Loading…",
        "Error: {code}": "Error: {code}",
        "Scene information control": "Scene information control"
      },
      "pt-BR": {
        "Scene information": "Informações da cena",
        "Close": "Fechar",
        "Grid": "Grade",
        "Refresh": "Atualizar",
        "Loading…": "Carregando…",
        "Error: {code}": "Erro: {code}",
        "Scene information control": "Controle de informações da cena"
      }
    });
  },
  register({ register }) {
    register("scene.controls", { mode: "augment", mount: this.mount });
  },
  async mount({ root, context, api, storage, viewport, events, signal, onDispose }) {
    const el = (tag, text) => {
      const node = root.ownerDocument.createElement(tag);
      if (text !== undefined) node.textContent = text;
      return node;
    };
    const t = (key, params) => api.i18n.t(key, params);
    const panel = el("section"); panel.className = "gw-example";
    const heading = el("h3", t("Scene information control"));
    const output = el("pre"); output.setAttribute("role", "status");
    panel.append(heading, output); root.append(panel);
    onDispose(() => panel.remove());
    const report = error => {
      if (!signal.aborted) output.textContent = t("Error: {code}", { code: error.code ?? "unavailable" });
    };
    const button = el("button", t("Scene information"));
    button.type = "button";
    panel.append(button);
    for (const type of ["pointerdown", "mousedown", "click"]) {
      panel.addEventListener(type, event => event.stopPropagation(), { signal });
    }
    let modal;
    onDispose(() => modal?.close(true));
    button.addEventListener("click", async () => {
      button.disabled = true;
      try {
        const scene = await api.maps.get(context.sceneId, {}, { signal });
        if (signal.aborted) return;
        modal?.close(true);
        const section = el("section");
        section.className = "gw-example";
        section.setAttribute("aria-label", t("Scene information"));
        section.append(el("h3", scene.name), el("p", context.width + " × " + context.height + " · " + t("Grid") + ": " + context.grid.size + "px / " + context.grid.distance + " " + context.grid.unit));
        const close = el("button", t("Close"));
        close.type = "button";
        close.addEventListener("click", () => section.close(), { signal });
        section.append(close);
        modal = api.ui.openModal(section);
      } catch (error) { report(error); }
      finally { if (!signal.aborted) button.disabled = false; }
    }, { signal });
  },
  stop() {
    // Mount and module lifetimes already dispose styles, catalogs and subscriptions.
  }
};

    Resultado esperado e liberação

    Adicione um botão funcional que leia a cena da montagem e mostre dimensões e grade no modal nativo.

    A interface nativa continua funcionando. Fechar a ficha, trocar a cena, sair da mesa ou desativar o módulo aborta a montagem. Os listeners usam signal; os eventos e elementos próprios são liberados por onDispose. A leitura assíncrona verifica o aborto e descarta respostas antigas antes de desenhar. Erros autorizados aparecem por error.code, sem esconder falhas de rede.

    Valide em uma mesa descartável

    1. Mova, amplie e troque a cena. Abra e feche o modal pelo teclado e desative o módulo enquanto ele estiver aberto.

    2. Abra/feche três vezes e desative durante uma leitura ou modal pendente. Confira que nenhum painel ou erro antigo reaparece após o encerramento.

    3. Teste estado vazio, nomes longos, teclado e janela estreita. Compare contas de mestre e jogador.

    4. Confira o console. Estes exemplos têm testes do contrato de runtime; instalação e aparência ainda precisam ser validadas no host alvo.
