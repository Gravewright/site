    GRAVEWRIGHT / Docs para devs

    Use a IA com o projeto como contexto.

    Escolha uma tarefa, copie um prompt e confira o resultado no código real e nos contratos suportados.

    Como usar a IA↗

    Como usar a IA para criar um sistema de RPG

    Crie fichas, modelos de itens e automações em um único pacote instalável, compatível com a versão do host que você usa.

    Como usar a IA↗

    Como usar a IA para criar um módulo de interface

    Adicione uma função útil usando a API de navegador, as permissões e o ciclo de vida dos módulos.

    Como usar a IA↗

    Como usar a IA para criar uma integração Python

    Use a interface Python pública em código confiável, preservando autorização por campanha e transações.

    Como usar a IA↗

    Como usar a IA para planejar um Objeto Inteligente

    Transforme uma interação em um plano de nós do Map Builder, depois simule e teste na mesa.

    Como usar a IA↗

    Como usar a IA para investigar um bug

    Forneça um caso reproduzível, encontre o domínio responsável e comprove a causa antes de alterar código.

    Como usar a IA↗

    Como usar a IA para escrever testes úteis

    Transforme uma mudança de comportamento em cobertura focada com Django, node:test ou Playwright e dados descartáveis.

    Como usar a IA↗

    Como usar a IA para traduzir uma extensão

    Prepare catálogos em inglês, português e espanhol pelo mecanismo oficial de tradução.

    Como usar a IA↗

    Como usar a IA para contribuir com o core

    Prepare uma alteração focada na camada correta, com contratos compatíveis, documentação alinhada e validação verificável.
