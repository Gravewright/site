    Todas as capacidades de extensão e onde implementá-las

    Mapa explícito de cada método para seu projeto, helpers, superfícies, integrações de servidor e limites da release.

    Como usar este mapa

    Este índice cruza os contratos públicos da revisão 04f0c1e do host 0.3.2 com os projetos de implementação. Ele cobre 213 métodos da API de domínio, 17 operações do SDK original, 13 superfícies e os helpers de ciclo de vida. Cada método aponta para um tutorial executável ou para o guia canônico com contrato, permissões e exemplos. Os projetos antigos mantêm sua versão de host declarada; métodos adicionados na 0.3.2 são identificados pela referência atual, sem atribuí-los retroativamente aos projetos antigos.

    Comece pelo resultado que quer construir, e use a tabela para localizar uma capacidade específica. Uma receita pode reunir várias chamadas porque criar, configurar, consultar e apagar fazem parte do mesmo recurso. As receitas executam apenas por clique e identificam ações destrutivas. Use uma instalação/campanha descartável.

    Não existe um enum global de tipos de módulo. “Compêndio” pode significar pack mutável da campanha, catálogo instalado com um sistema ou catálogo local do operador; cada origem tem regras próprias. A montagem depende da superfície, não do nome que você deu ao módulo.

    Todos os métodos de domínio

    Em métodos genéricos, use api.dominio.metodo(payload, {signal, requestId}) com os campos da receita. Leituras não precisam requestId. list/get são projeções autorizadas de state. actors.sheet, dice.roll, table.search, chat.remove e outras conveniências têm assinaturas próprias demonstradas nos guias. Não confunda o nome JavaScript com a ação da fachada Python.

    Map Builder e automação visual

    Os quatro donos door/lever/torch/region, as conexões execution/data e os 48 node.type têm grafo completo, JSON e passos no editor. O catálogo de nós explica recursos, alvos e efeitos. Use a ação nativa de Test behavior/playtest antes de aplicar na cena. Esses grafos são documentos de desenvolvimento, não uma API browser para importar qualquer JSON nem um campo novo do manifesto.

    O tutorial de cenas mostra a API pública de camadas/objetos. Criar novos kinds ou portas do editor exige contribuição ao core e seus testes; a release 0.3.2 não promete uma API de plugin para registrar tipos arbitrários de nó.

    Integrações de servidor e limites da release

    A integração Django mostra Context.from_request, comandos públicos, rotas autenticadas/CSRF e sinais depois do commit. As fachadas Python api.actors/tokens/maps/journals/items/combat/cards/audio/compendiums/clocks/clues/mindmaps/resources/chat/dice/table/events têm assinaturas na referência. O contexto carrega IDs, sem congelar permissões; cada serviço revalida acesso. Contas, administração, instalação e campanhas são adaptadores globais da aplicação, não métodos do api entregue a uma montagem: consulte a referência de adaptadores para ferramentas do operador.

    Não há maps.create. A API 0.3.2 acrescenta adaptadores de arquivos, incluindo audio.upload e maps.upload/importUniversalVtt; passe um File real pela API documentada. Tutoriais antigos podem preparar cenas e arquivos pela interface nativa para manter sua compatibilidade declarada. Não há SQL/Python arbitrário por chamada de módulo browser, permissão de GM implícita, mudança de campanha por UUID nem bypass de conteúdo privado. system.combat aceita iniciativa declarativa. Provedores Python existentes são código confiável de servidor; não justificam distribuir um novo RPG como sistema mais Server Rules separado. Uma necessidade sem contrato deve ser apresentada como limitação, preservando a versão solicitada.

    Como conferir a cobertura ao evoluir o host

    Este mapa usa uma cópia versionada de frontend.json e registry.json em extension-contracts.json. Ao atualizar a documentação para outro host, compare os arquivos fonte e a revisão, atualize os projetos e execute suas receitas contra os serviços reais. Compatibilidade de nome não prova payload, permissão, efeito visual ou transação. Refaça testes de escrita e dados independentes em fixtures novas.
