    Como criar um módulo de ferramentas de token

    Coloque, mova, duplique, configure e remova tokens; controle visão, ocultação e condições com duração.

    O projeto que você vai criar

    Crie Token workshop em um módulo comum. Coloque dois tokens descartáveis na cena anterior; teste movimento, duplicação snapshot, rotação/elevação, visão, ocultação e condição original. Mantenha tokens para o tutorial de combate antes da remoção.

    Host alvo: Gravewright 0.3.0. As ações rodam somente quando você clica Run action; leituras e escritas usam a conta conectada. O painel de demonstração está em inglês. Cada receita abaixo informa os dados de entrada e o resultado concreto.

    1. Crie os arquivos

    Crie uma pasta tokens-workshop. Salve os arquivos mostrados abaixo em UTF-8, ou baixe o projeto completo. manifest.json fica na raiz. Não há dependências npm nem build de JavaScript.

    text
    tokens-workshop/
  manifest.json
  main.mjs
  recipes.mjs
  styles.css
  LICENSE.txt

    Conclua Scene workshop e guarde ID da cena. Crie ator descartável pelo diretório nativo Actors com o sistema escolhido, ou siga tutorial de atores. Copie IDs reais em Inspect. O módulo chama api.tokens pública. GridX/gridY são células de posicionamento; paredes nativas usam pixels da cena.

    2. Empacote, instale e ative

    Partindo da pasta do projeto, execute no PowerShell:

    powershell
    python -m json.tool manifest.json
python -m zipfile -c ../tokens-workshop-1.0.0.zip manifest.json main.mjs recipes.mjs styles.css LICENSE.txt
python -m zipfile -l ../tokens-workshop-1.0.0.zip

    No Linux/macOS, substitua python por python3 no mesmo comando. A listagem precisa mostrar manifest.json na raiz. Como proprietário, abra Inside → Módulos → Instalar módulo → Instalar de ZIP, selecione o ZIP e clique Instalar. Como GM, abra a campanha, use o botão Gravewright da mesa → Extensions e clique Activate na versão 1.0.0 de Token workshop. Feche o menu e clique no botão Token workshop. Se precisar de detalhes de cada tela, veja seu primeiro módulo.

    O projeto fica inativo até a seleção na mesa. Teste uma extensão de demonstração por vez, pois seus botões usam a mesma posição. Para novos bytes, mude version para 1.0.1, gere outro ZIP, instale e ative essa versão; não edite o pacote instalado.

    3. Execute cada receita

    Consultar atores disponíveis e tokens da cena

    Cole o Scene ID do tutorial de mapas. Copie ID de ator legível para Place e depois ID de token para as demais ações.

    javascript
    async ({api,context,signal},v) => {

  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    return {actors:await api.actors.list({},read),tokens:await api.tokens.list({mapId:v.mapId},read)};
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: Metadados autorizados e IDs, versões, posições, visão e condições visíveis dos tokens.

    Como conferir: Compare GM e jogador: tokens ocultos e condições privadas são filtrados antes da entrega.

    Colocar token de ator na cena de teste

    Crie antes um ator descartável original pela ficha nativa/do sistema. GridX/gridY usam células, não pixels da cena. O host valida limites e tamanho.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    await api.actors.get(v.actorId,{},read);
    const created=await api.tokens.place({mapId:v.mapId,actorId:v.actorId,gridX:v.x,gridY:v.y},write());
    return {createdIds:created.createdIds,tokens:created.tokens};
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: ID criado e projeção atual. O host decide o modo vinculado/snapshot.

    Como conferir: Encontre em grid2,2. O primeiro token pode ser vinculado; outra colocação do mesmo ator pode converter vínculos existentes em snapshots independentes pelo serviço nativo.

    Mover token controlado e destrancado

    Informe token e destino próximo. Path:[] solicita segmento direto; pontos intermediários usam as mesmas células. Movimento de jogador verifica paredes e controle.

    javascript
    async ({api,context,signal},v) => {

  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    const token=await api.tokens.get(v.id,{mapId:v.mapId},read);
    if(!token.canControl||token.locked) throw new Error('Choose a controlled unlocked token');
    return await api.tokens.move({mapId:v.mapId,id:token.id,expectedVersion:token.version,gridX:v.x,gridY:v.y,path:[]},write());
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: Mesmo token na posição aceita, com versão incrementada.

    Como conferir: Teste como jogador controlador: caminho livre funciona, parede bloqueia sem alterar posição e expectedVersion antigo causa conflito.

    Duplicar um token do tutorial

    Use o token colocado acima. O serviço nativo cria snapshot independente e escolhe deslocamento dentro do mapa.

    javascript

    Resultado esperado: Outro ID, normalmente deslocado uma célula, com linkMode snapshot.

    Como conferir: Confira ambos IDs e abra suas fichas. Copie ID da cópia para limpeza ou combate.

    Configurar rotação, elevação e disposição

    Configure um token descartável. Mantenha locked false para mover. Elevação afeta elegibilidade em regiões. Jogador pode girar token controlado só com values contendo rotation; esta receita com vários campos é de GM.

    javascript
    async ({api,context,signal},v) => {

  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    const token=await api.tokens.get(v.id,{mapId:v.mapId},read);
    await api.tokens.configure({mapId:v.mapId,tokenIds:[token.id],expectedVersion:token.version,values:{rotation:v.rotation,elevation:v.elevation,disposition:v.disposition,locked:v.locked}},write());
    return await api.tokens.get(token.id,{mapId:v.mapId},read);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: Rotação, elevação, disposição e trava solicitadas, preservando ator/ficha.

    Como conferir: Confira o editor nativo e confirme que locked impede mover até ser retirado.

    Habilitar e configurar visão do token

    Use o token colocado; range é distância não negativa em células. Para ver linha de visão, configure iluminação dinâmica na cena e use jogador controlador.

    Ocultar e mostrar token de teste

    Execute com Hidden marcado, confira a conta de jogador, depois desmarque e repita. Isso altera visibilidade do token, não permissões do ator.

    Adicionar condição original com duração

    Use nome original. É marcador genérico, sem regra de livro. Copie condition_id para Remove condition. Duração avança por eventos reais de combate para token participante.

    javascript
    async ({api,context,signal},v) => {

  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    await api.tokens.get(v.id,{mapId:v.mapId},read);
    if(!['everyone','gm'].includes(v.visibility)) throw new Error('Use everyone or gm');
    if(!Number.isInteger(v.rounds)||v.rounds<1) throw new Error('Use a positive integer duration');
    if(v.visibility==='gm'&&context.role!=='gm') throw new Error('GM required for hidden conditions');
    await api.tokens.addCondition({mapId:v.mapId,tokenIds:[v.id],label:v.label,description:'Original tutorial marker with no RPG rules.',kind:'positive',visibility:v.visibility,duration:{type:'rounds',value:v.rounds,expires:'end'}},write());
    return await api.tokens.get(v.id,{mapId:v.mapId},read);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: Condição com condition_id único e duração rounds/end explícita.

    Como conferir: Como jogador, acrescente apenas em token controlado com visibility everyone. Condição GM privada deve faltar na projeção de jogador.

    Remover a condição escolhida

    Cole condition_id exato, não o rótulo. Remova somente o marcador criado no tutorial.

    javascript
    async ({api,context,signal},v) => {

  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    const token=await api.tokens.get(v.id,{mapId:v.mapId},read);
    if(!token.conditions.some(item=>item.condition_id===v.conditionId)) throw new Error('Choose a visible condition from this token');
    await api.tokens.removeCondition({mapId:v.mapId,tokenIds:[v.id],conditionId:v.conditionId},write());
    return await api.tokens.get(v.id,{mapId:v.mapId},read);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: A condição escolhida desaparece e as demais permanecem.

    Como conferir: Compare antes/depois. Jogador não pode descobrir/remover condição privada adivinhando ID.

    Remover token descartável

    Use apenas token/cópia do tutorial, depois de limpar o combate. Remover token não apaga seu ator.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    if(!v.confirm) throw new Error('Confirm the disposable token');
    await api.tokens.get(v.id,{mapId:v.mapId},read);
    await api.tokens.remove({mapId:v.mapId,tokenIds:[v.id]},write());
    return await api.tokens.list({mapId:v.mapId},read);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.tokens.state({mapId:v.mapId},read);
    throw problem;
  }
}

    Resultado esperado: Token ausente; ator permanece em Actors.

    Como conferir: Confira cena, diretório e preservação dos outros IDs de token.

    4. Entenda e adapte os arquivos completos

    main.mjs desenha apenas o lançador e o formulário. recipes.mjs contém as ações: para adaptar o comportamento, altere a função run da receita desejada, mantendo sua assinatura. O formulário passa tipos reais (number, boolean e File), bloqueia requisições simultâneas e desenha resultados com textContent. Não há avaliação de código fornecido pelo usuário. api, host, assets e storage pertencem à montagem; signal cancela trabalho ao desativar. O modal não fecha durante uma operação pendente e é liberado ao abortar a montagem. A função de negócio continua responsável por revisões, permissões e sequência transacional.

      let modal,pending=false;
      button.addEventListener('click',event=>{
        event.stopPropagation();
        if(modal?.isConnected) { modal.focus();return; }
        const panel=doc.createElement('section');
        panel.className="tutorial-workbench-tokens-workshop";
        panel.setAttribute('role','dialog');panel.setAttribute('aria-modal','true');

        }
        const form=doc.createElement('form'),fields=doc.createElement('div');

        const run=doc.createElement('button');run.type='submit';run.textContent='Run action';

            if(field.accept)input.accept=field.accept;
            label.append(input);fields.append(label);
          }
          output.textContent='';

          event.preventDefault();if(pending)return;

          }
          pending=true;choose.disabled=true;run.disabled=true;close.disabled=true;
          for(const input of fields.querySelectorAll('input'))input.disabled=true;
          output.textContent='Running…';
          try {
            const value=await recipe.run({api,host,assets,storage,context,events,viewport,signal,onDispose},values);
            if(!signal.aborted)output.textContent=typeof value==='string'?value:JSON.stringify(value??null,null,2);
          } catch(error) {
            if(!signal.aborted)output.textContent=String(error.code||error.message||'unavailable');
          } finally {
            pending=false;
            if(!signal.aborted){choose.disabled=false;run.disabled=false;close.disabled=false;for(const input of fields.querySelectorAll('input'))input.disabled=false;}
          }
        },{signal});
        close.addEventListener('click',()=>void modal.close(),{signal});
        modal=api.ui.openModal(panel,{canClose:()=>!pending||signal.aborted});
      },{signal});
      onDispose(()=>{button.remove();if(modal)void modal.close();});
    });
  },
  stop() {}
};

    5. Permissões, falhas e teste final

    Cada gravação exige Run action explícito. Leituras usam projeções autorizadas; escritas mantêm permissões nativas e UUID novo por operação. Update de cena/objeto, movimento/configuração de token e combate usam seus campos reais de revisão. Alguns comandos nativos de seleção não aceitam revisão esperada nesta versão; os exemplos não inventam esse parâmetro. Em conflito, a receita relê o estado e para. Revise e execute conscientemente nova operação. Chamadas diferentes são transações distintas: uma já concluída não é revertida se uma leitura posterior falhar. Desativar aborta trabalho da montagem, sem desfazer commit.

    Use GM, jogador controlador e não controlador. Teste token trancado, movimento bloqueado, filtragem de token/condição privada, expectedVersion antigo e token de outra cena. Avanço de duração pertence ao combate real, sem timer local. Após reconexão, consulte o estado em vez de repetir mutações como efeitos de notificações.
