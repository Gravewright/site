    Como criar um módulo de ferramentas de cena

    Monte módulo que consulta camadas, edita metadados/pastas, cria uma porta nativa e transmite cena de teste.

    O projeto que você vai criar

    Crie Scene workshop, módulo de navegador com laboratório em modal nativo. Siga uma sequência concreta: consultar cena descartável, renomear, organizar pasta, criar/editar/operar porta e transmitir conscientemente. Exclua os dados só depois dos tutoriais de tokens e combate.

    Host alvo: Gravewright 0.3.0. As ações rodam somente quando você clica Run action; leituras e escritas usam a conta conectada. O painel de demonstração está em inglês. Cada receita abaixo informa os dados de entrada e o resultado concreto.

    1. Crie os arquivos

    Crie uma pasta maps-workshop. Salve os arquivos mostrados abaixo em UTF-8, ou baixe o projeto completo. manifest.json fica na raiz. Não há dependências npm nem build de JavaScript.

    text
    maps-workshop/
  manifest.json
  main.mjs
  recipes.mjs
  styles.css
  LICENSE.txt

    Em campanha descartável, crie uma cena vazia de pelo menos8×8 células pelo fluxo nativo Scenes → New scene → Map Builder, depois Generate scene. Comece sem conteúdo valioso. A API de domínio do navegador não tem maps.create para raster/projeto Builder. Use o Map Builder para autoria; geração do projeto é separada dos comandos abaixo.

    2. Empacote, instale e ative

    Partindo da pasta do projeto, execute no PowerShell:

    powershell
    python -m json.tool manifest.json
python -m zipfile -c ../maps-workshop-1.0.0.zip manifest.json main.mjs recipes.mjs styles.css LICENSE.txt
python -m zipfile -l ../maps-workshop-1.0.0.zip

    No Linux/macOS, substitua python por python3 no mesmo comando. A listagem precisa mostrar manifest.json na raiz. Como proprietário, abra Inside → Módulos → Instalar módulo → Instalar de ZIP, selecione o ZIP e clique Instalar. Como GM, abra a campanha, use o botão Gravewright da mesa → Extensions e clique Activate na versão 1.0.0 de Scene workshop. Feche o menu e clique no botão Scene workshop. Se precisar de detalhes de cada tela, veja seu primeiro módulo.

    O projeto fica inativo até a seleção na mesa. Teste uma extensão de demonstração por vez, pois seus botões usam a mesma posição. Para novos bytes, mude version para 1.0.1, gere outro ZIP, instale e ative essa versão; não edite o pacote instalado.

    3. Execute cada receita

    Consultar cenas, pastas e camadas nativas

    Execute primeiro sem Scene ID. Copie o ID da cena de teste, preencha e repita para consultar paredes, imagens, luzes, neblina, iluminação e suas versões.

    javascript
    async ({api,context,signal},v) => {

  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    const directory=await api.maps.state({},read);
    const layers=v.mapId.trim()?await api.maps.layers({mapId:v.mapId.trim()},read):null;
    return {directory,layers};
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: IDs autorizados, activeMapId e navigatingMapId; camadas nativas da cena quando informada.

    Como conferir: Compare o diretório de GM com a conta de jogador. O estado de jogador omite cenas privadas, regiões e grafos privados.

    Renomear cena de teste e definir a grade

    Use cena descartável. Name e gridVisible são os ajustes enviados; os demais são preservados. Não envie toda a projeção como settings.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    const before=await api.maps.get(v.mapId,{},read);
    await api.maps.update({mapId:before.id,version:before.version,settings:{name:v.name,gridVisible:v.gridVisible}},write());
    return await api.maps.get(before.id,{},read);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: Mesmo ID, novo nome, visibilidade da grade escolhida e nova versão inteira.

    Como conferir: Abra os ajustes nativos e confira nome/grade; imageScale, gridSize e unidades continuam iguais.

    Use a pasta criada acima. Parent vazio coloca na raiz. O servidor rejeita ciclos, pastas de outra campanha e profundidade excedida.

    Mover cena para a pasta do tutorial

    Cole os IDs da cena e pasta. Este comando usa groupId, não o folder_id dos diários.

    Como conferir: Localize a mesma cena em Workshop rooms. ID e objetos nativos permanecem.

    Criar porta nativa por updateObjects

    Use cena de pelo menos 8 células de largura. As coordenadas são pixels da cena, diferentes das células de token.move. Os pontos precisam diferir. Cria porta nativa simples, sem blueprint ou imagem.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    await api.maps.get(v.mapId,{},read);
    const result=await api.maps.updateObjects({mapId:v.mapId,area:'walls',action:'create',data:{x1:v.x1,y1:v.y1,x2:v.x2,y2:v.y2,kind:'door',door_state:'closed'}},write());
    return {created:result.wall,layers:await api.maps.layers({mapId:v.mapId},read)};
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: Registro de parede com kind door, ID e versão. Copie seu ID.

    Como conferir: Abra Walls na cena nativa e localize a porta horizontal. Confira os pontos na projeção.

    Ajustar ponto da porta com sua versão

    Use a porta criada acima. Só x2 muda; o validador nativo preserva os demais campos. Versão da cena e versão do objeto são diferentes.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};

  try {
    const layers=await api.maps.layers({mapId:v.mapId},read);
    const door=layers.walls.find(row=>row.id===v.doorId&&row.kind==='door');
    if(!door) throw new Error('Choose a door from this scene');
    await api.maps.updateObjects({mapId:v.mapId,area:'walls',action:'update',data:{wall_id:door.id,version:door.version,x2:v.x2}},write());
    return (await api.maps.layers({mapId:v.mapId},read)).walls.find(row=>row.id===door.id);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: Porta maior/menor, mesmo ID e versão de objeto incrementada.

    Como conferir: Confira preservação de x1/y1/y2, apresentação e canais de barreira. Edição nativa intercalada deve causar conflict.

    Abrir ou fechar a porta simples de teste

    Informe open e execute; depois closed e repita. A receita usa porta simples. Em Objeto Inteligente, a interação pode executar grafos em vez de uma alternância simples.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    if(!['open','closed','locked'].includes(v.state)) throw new Error('Use open, closed or locked');
    const layers=await api.maps.layers({mapId:v.mapId},read);
    const door=layers.walls.find(row=>row.id===v.doorId&&row.kind==='door');
    if(!door||door.blueprint) throw new Error('Choose the plain tutorial door without a blueprint');
    return await api.maps.updateObjects({mapId:v.mapId,area:'walls',action:'door',data:{wall_id:door.id,door_state:v.state}},write());
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: A porta simples abre/fecha na cena nativa.

    Como conferir: Observe geometria e bloqueio. Teste interação de jogador pelos controles nativos, incluindo recusa de porta trancada.

    Transmitir a cena de teste preparada

    Escolha a cena descartável preparada e marque a transmissão. Activate torna a cena visível e altera a transmissão da campanha.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});
    return {signal,requestId:crypto.randomUUID()};
  };
  try {
    if(!v.confirm) throw new Error('Confirm the test scene broadcast');
    await api.maps.get(v.mapId,{},read);
    await api.maps.activate({mapId:v.mapId},write());
    return await api.maps.state({},read);
  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: activeMapId corresponde à cena; jogadores conectados mudam para ela.

    Como conferir: Use segunda conta de jogador. Confira que a transmissão muda só depois de Run action com a opção marcada.

    Excluir somente a porta do tutorial

    Use somente a porta criada no tutorial e confirme. Apagar Objeto Inteligente pode executar destruição configurada; a porta simples do tutorial não tem grafo.

    javascript
    async ({api,context,signal},v) => {
  if(context.role!=='gm') throw new Error('GM required');
  const read={signal};
  const write=()=>{
    if(signal?.aborted) throw Object.assign(new Error('Mount closed'),{code:'cancelled'});

  } catch(problem) {
    if(problem.code==='conflict'&&!signal?.aborted) await api.maps.state({},read);
    throw problem;
  }
}

    Resultado esperado: A porta selecionada desaparece e as demais paredes permanecem.

    Como conferir: Compare paredes antes/depois e confirme remoção só do ID copiado.

    Remover pasta de teste preservando cenas

    Use a pasta criada aqui. Recursive:false move cenas/subpastas ao pai, em vez de apagar a árvore.

    Excluir a cena descartável por último

    Execute por último e só na cena descartável, depois dos tutoriais de tokens/combate. Excluir cena também remove seu conteúdo.

    Como conferir: Confira que as outras cenas/campanhas permanecem. Não use em mapa de campanha existente.

    4. Entenda e adapte os arquivos completos

    main.mjs desenha apenas o lançador e o formulário. recipes.mjs contém as ações: para adaptar o comportamento, altere a função run da receita desejada, mantendo sua assinatura. O formulário passa tipos reais (number, boolean e File), bloqueia requisições simultâneas e desenha resultados com textContent. Não há avaliação de código fornecido pelo usuário. api, host, assets e storage pertencem à montagem; signal cancela trabalho ao desativar. O modal não fecha durante uma operação pendente e é liberado ao abortar a montagem. A função de negócio continua responsável por revisões, permissões e sequência transacional.

            values[input.name]=input.type==='file'?input.files[0]:input.type==='checkbox'?input.checked:input.type==='number'?Number(input.value):input.value;
          }
          pending=true;choose.disabled=true;run.disabled=true;close.disabled=true;
          for(const input of fields.querySelectorAll('input'))input.disabled=true;
          output.textContent='Running…';
          try {
            const value=await recipe.run({api,host,assets,storage,context,events,viewport,signal,onDispose},values);
            if(!signal.aborted)output.textContent=typeof value==='string'?value:JSON.stringify(value??null,null,2);
          } catch(error) {
            if(!signal.aborted)output.textContent=String(error.code||error.message||'unavailable');
          } finally {
            pending=false;
            if(!signal.aborted){choose.disabled=false;run.disabled=false;close.disabled=false;for(const input of fields.querySelectorAll('input'))input.disabled=false;}
          }
        },{signal});
        close.addEventListener('click',()=>void modal.close(),{signal});
        modal=api.ui.openModal(panel,{canClose:()=>!pending||signal.aborted});
      },{signal});
      onDispose(()=>{button.remove();if(modal)void modal.close();});
    });
  },
  stop() {}

    5. Permissões, falhas e teste final

    Cada gravação exige Run action explícito. Leituras usam projeções autorizadas; escritas mantêm permissões nativas e UUID novo por operação. Update de cena/objeto, movimento/configuração de token e combate usam seus campos reais de revisão. Alguns comandos nativos de seleção não aceitam revisão esperada nesta versão; os exemplos não inventam esse parâmetro. Em conflito, a receita relê o estado e para. Revise e execute conscientemente nova operação. Chamadas diferentes são transações distintas: uma já concluída não é revertida se uma leitura posterior falhar. Desativar aborta trabalho da montagem, sem desfazer commit.

    Teste filtragem GM/jogador, revisão antiga de cena e de porta, ciclo de pasta negado e desativação durante leitura. Activate transmite explicitamente aos jogadores. Limite do Map Builder: este pacote não cria JSON de Blueprint nem usa rotas privadas. Use o editor real, Simulate e Test behavior para criar automação; depois Generate/Update scene. Quatro kinds de Blueprint, 42 nós completos e conexões execution/data trazem receitas completas.
