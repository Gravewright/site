    Como criar, sortear e restaurar tabelas de rolagem

    Crie uma tabela de diário original, altere um peso preservando dados e publique sorteios nativos com ou sem reposição.

    O projeto que você vai criar

    Crie tabela de clima do porto com duas entradas, leia seu formato real, altere um peso, sorteie até esgotar e restaure. O tipo é journal_type roll_table, diferente de pack de compêndio ou tabela específica de sistema.

    Host alvo: Gravewright 0.3.0. As ações rodam somente quando você clica Run action; leituras e escritas usam a conta conectada. O painel de demonstração está em inglês. Cada receita abaixo informa os dados de entrada e o resultado concreto.

    1. Crie os arquivos

    Crie uma pasta roll-tables. Salve os arquivos mostrados abaixo em UTF-8, ou baixe o projeto completo. manifest.json fica na raiz. Não há dependências npm nem build de JavaScript.

    text
    roll-tables/
  manifest.json
  main.mjs
  recipes.mjs
  styles.css
  LICENSE.txt

    Use campanha descartável como mestre e uma segunda conta de jogador para conferir audiência. Use resultados originais. Informe cena autorizada apenas se o sorteio deve ter aquela cena como alvo; caso contrário, usa o contexto nativo de transmissão.

    2. Empacote, instale e ative

    Partindo da pasta do projeto, execute no PowerShell:

    powershell
    python -m json.tool manifest.json
python -m zipfile -c ../roll-tables-1.0.0.zip manifest.json main.mjs recipes.mjs styles.css LICENSE.txt
python -m zipfile -l ../roll-tables-1.0.0.zip

    No Linux/macOS, substitua python por python3 no mesmo comando. A listagem precisa mostrar manifest.json na raiz. Como proprietário, abra Inside → Módulos → Instalar módulo → Instalar de ZIP, selecione o ZIP e clique Instalar. Como GM, abra a campanha, use o botão Gravewright da mesa → Extensions e clique Activate na versão 1.0.0 de Roll table tools. Feche o menu e clique no botão Roll table tools. Se precisar de detalhes de cada tela, veja seu primeiro módulo.

    O projeto fica inativo até a seleção na mesa. Teste uma extensão de demonstração por vez, pois seus botões usam a mesma posição. Para novos bytes, mude version para 1.0.1, gere outro ZIP, instale e ative essa versão; não edite o pacote instalado.

    3. Execute cada receita

    Criar uma tabela original com pesos

    Como mestre, crie journal_type roll_table e configure duas entradas completas. Pesos 3 e 1 produzem probabilidades diferentes. Sem reposição, entradas sorteadas deixam de participar até reset.

    javascript
    async ({api,context,signal},v)=>{if(context.role!=='gm')throw new Error('GM required.');const created=await api.journals.create({title:v.title,journal_type:'roll_table'},{signal,requestId:crypto.randomUUID()});try{await api.journals.update({journal_id:created.journal_id,version:created.version,title:v.title,visibility:'private',data:{withReplacement:v.replacement,resultVisibility:v.secret?'gm':'public',entries:[{id:'clear',name:'Clear sky',weight:3,result:'The beacon is visible across the bay.',active:true,drawn:false,sortOrder:10},{id:'fog',name:'Fog',weight:1,result:'The boats wait for the fog to lift.',active:true,drawn:false,sortOrder:20}]}},{signal,requestId:crypto.randomUUID()});return api.journals.get(created.journal_id,{}, {signal});}catch(error){throw new Error('Roll table '+created.journal_id+' exists; configuration failed: '+(error.code||error.message)+'. Repair this table before creating another.');}}

    Resultado esperado: Uma tabela com totalWeight 4, IDs próprios de entradas e audiência escolhida.

    Como conferir: Abra o diretório ou documento nativo e compare o estado do servidor. Compare mestre e jogador; apenas conteúdo autorizado pode aparecer.

    Ler pesos, resultados e marcadores de sorteio

    Use o UUID da tabela. roll_table contém entradas e totalWeight; texto exclusivo do mestre é removido para os demais membros.

    javascript
    async ({api,signal},v)=>{const row=await api.journals.get(v.id,{}, {signal});if(row.type!=='roll_table')throw new Error('Choose a roll_table journal.');return row;}

    Resultado esperado: Entradas autorizadas com weight, active, drawn e sortOrder.

    Como conferir: Dê leitura ao jogador e compare uma tabela secreta. Ele deve receber result vazio e não pode rolá-la.

    Alterar um peso preservando as demais entradas

    Como mestre, use o ID exato da entrada. Copie a tabela completa e altere um peso; totalWeight é calculado e não entra nos dados enviados.

    javascript
    async ({api,context,signal},v)=>{if(context.role!=='gm')throw new Error('GM required to preserve complete results.');if(!Number.isInteger(v.weight)||v.weight<1||v.weight>1000000)throw new Error('Invalid weight.');const row=await api.journals.get(v.id,{}, {signal});if(row.type!=='roll_table')throw new Error('Choose a roll_table.');const data=structuredClone(row.roll_table);if(!data.entries.some(entry=>entry.id===v.entryId))throw new Error('Entry not found.');data.entries=data.entries.map(entry=>entry.id===v.entryId?{...entry,weight:v.weight}:entry);delete data.totalWeight;await api.journals.update({journal_id:row.id,version:row.version,title:row.title,visibility:row.visibility,data},{signal,requestId:crypto.randomUUID()});return api.journals.get(row.id,{}, {signal});}

    Resultado esperado: O peso escolhido muda e totalWeight é recalculado.

    Como conferir: Abra o diretório ou documento nativo e compare o estado do servidor. Compare mestre e jogador; apenas conteúdo autorizado pode aparecer.

    Sortear e publicar um resultado da tabela

    Execute como mestre. O comando nativo sorteia com pesos, persiste drawn quando necessário e publica no chat. O payload usa mapId para cena explícita.

    javascript
    async ({api,context,signal},v)=>{if(context.role!=='gm')throw new Error('GM required.');return api.journals.roll({journal_id:v.id,...(v.sceneId.trim()?{mapId:v.sceneId.trim()}:{})},{signal,requestId:crypto.randomUUID()});}

    Resultado esperado: A entrada escolhida e message_id; o chat nativo mostra o resultado autorizado.

    Como conferir: Sem reposição, role duas vezes e confira entradas distintas; a terceira deve falhar até reset. Não repita o mesmo sorteio com UUID novo após perder a resposta.

    Restaurar marcadores sem alterar resultados

    Use o UUID da tabela esgotada. Reset define drawn falso em cada entrada; não limpa o chat nem substitui o texto da tabela.

    javascript
    async ({api,context,signal},v)=>{if(context.role!=='gm')throw new Error('GM required.');await api.journals.reset({journal_id:v.id},{signal,requestId:crypto.randomUUID()});return api.journals.get(v.id,{}, {signal});}

    Resultado esperado: As entradas ativas participam novamente e totalWeight é restaurado.

    Como conferir: Abra o diretório ou documento nativo e compare o estado do servidor. Compare mestre e jogador; apenas conteúdo autorizado pode aparecer.

    4. Entenda e adapte os arquivos completos

    main.mjs desenha apenas o lançador e o formulário. recipes.mjs contém as ações: para adaptar o comportamento, altere a função run da receita desejada, mantendo sua assinatura. O formulário passa tipos reais (number, boolean e File), bloqueia requisições simultâneas e desenha resultados com textContent. Não há avaliação de código fornecido pelo usuário. api, host, assets e storage pertencem à montagem; signal cancela trabalho ao desativar. O modal não fecha durante uma operação pendente e é liberado ao abortar a montagem. A função de negócio continua responsável por revisões, permissões e sequência transacional.

    main.mjs

    javascript
    import {recipes} from './recipes.mjs';
export default {
  start({styles}) { styles.use('styles.css'); },
  register({register}) {
    register("table.interface", ({root,api,host,assets,storage,context,events,viewport,signal,onDispose}) => {
      const doc=root.ownerDocument;
      const button=doc.createElement('button');
      button.type='button';button.className='tutorial-launcher';
      button.textContent="Roll table tools";
      root.append(button);
      for(const type of ['pointerdown','mousedown'])button.addEventListener(type,event=>event.stopPropagation(),{signal});
      let modal,pending=false;
      button.addEventListener('click',event=>{
        event.stopPropagation();
        if(modal?.isConnected) { modal.focus();return; }
        const panel=doc.createElement('section');
        panel.className="tutorial-workbench-roll-tables";
        panel.setAttribute('role','dialog');panel.setAttribute('aria-modal','true');
        panel.setAttribute('aria-label',button.textContent);panel.tabIndex=-1;
        const title=doc.createElement('h2');title.textContent=button.textContent;panel.append(title);
        const choose=doc.createElement('select');choose.setAttribute('aria-label','Action');
        for(const recipe of recipes) {
          const option=doc.createElement('option');option.value=recipe.id;option.textContent=recipe.label;choose.append(option);
        }
        const form=doc.createElement('form'),fields=doc.createElement('div');
        const description=doc.createElement('p');
        const run=doc.createElement('button');run.type='submit';run.textContent='Run action';
        const close=doc.createElement('button');close.type='button';close.textContent='Close';
        const output=doc.createElement('pre');output.setAttribute('role','status');output.setAttribute('aria-live','polite');
        form.append(description,fields,run,close,output);panel.append(choose,form);
        function renderFields(){
          const recipe=recipes.find(item=>item.id===choose.value);fields.replaceChildren();
          description.textContent=recipe.description;
          for(const field of recipe.fields||[]) {
            const label=doc.createElement('label');label.textContent=field.label;
            const input=doc.createElement('input');input.name=field.name;input.type=field.type||'text';
            if(field.type==='number')input.step=String(field.step??'any');
            if(field.type==='checkbox')input.checked=!!field.value;
            else if(field.type!=='file')input.value=String(field.value??'');
            input.required=!!field.required;
            if(field.accept)input.accept=field.accept;
            label.append(input);fields.append(label);
          }
          output.textContent='';
        }
        choose.addEventListener('change',renderFields,{signal});renderFields();
        form.addEventListener('submit',async event=>{
          event.preventDefault();if(pending)return;
          const recipe=recipes.find(item=>item.id===choose.value),values={};
          for(const input of fields.querySelectorAll('input')) {
            values[input.name]=input.type==='file'?input.files[0]:input.type==='checkbox'?input.checked:input.type==='number'?Number(input.value):input.value;
          }
          pending=true;choose.disabled=true;run.disabled=true;close.disabled=true;
          for(const input of fields.querySelectorAll('input'))input.disabled=true;
          output.textContent='Running…';
          try {
            const value=await recipe.run({api,host,assets,storage,context,events,viewport,signal,onDispose},values);
            if(!signal.aborted)output.textContent=typeof value==='string'?value:JSON.stringify(value??null,null,2);
          } catch(error) {
            if(!signal.aborted)output.textContent=String(error.code||error.message||'unavailable');
          } finally {
            pending=false;
            if(!signal.aborted){choose.disabled=false;run.disabled=false;close.disabled=false;for(const input of fields.querySelectorAll('input'))input.disabled=false;}
          }
        },{signal});
        close.addEventListener('click',()=>void modal.close(),{signal});
        modal=api.ui.openModal(panel,{canClose:()=>!pending||signal.aborted});
      },{signal});
      onDispose(()=>{button.remove();if(modal)void modal.close();});
    });
  },
  stop() {}
};

    5. Permissões, falhas e teste final

    Somente mestres podem sortear ou restaurar. Um jogador com leitura vê metadados autorizados, mas não texto de resultado quando resultVisibility é gm. Com reposição falsa, duas entradas ativas permitem dois sorteios até esgotar. Reset restaura participação sem sortear ou limpar chat. Edições preservam todas as entradas e a versão exata; não envie projeção filtrada de jogador como tabela completa do mestre. Repare falha de configuração pelo UUID criado informado.

    Como usar a IA para estender este projeto

    text
    Estenda roll-tables no Gravewright 0.3.0 com [comportamento]. Leia normalize_roll_table_data, journals.types.apply e o mapeamento público. Preserve sorteio nativo com pesos, active/drawn, withReplacement, resultVisibility, roll/reset exclusivos do mestre, versão exata e UUID de tentativa. Entregue entradas completas e teste esgotamento, restauração, resultados privados e cena ausente.
