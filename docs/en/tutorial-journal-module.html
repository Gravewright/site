    How to create a journal module

    Build, install and run a normal module that creates private journals and appends saved GM session drafts.

    What you will build

    A normal browser module for Gravewright 0.3.0 with two working actions: create a private journal from the table, then append a session draft to an existing journal. The sheet action is Add session section. It writes a Session notes page under Sessions, containing original draft text with audience gm. It preserves the existing authored text.

    The package uses public api.journals.state, create and update. It imports no private host code and requires no Django app. Both surfaces use mode: augment, retaining the native editor.

    1. Start with the files

    Use a disposable development installation of host0.3.0, an installation-owner account for installation and a GM account in a campaign. You need a text editor and the project's prepared Python environment. There are no npm dependencies or frontend build. Create a session-journal folder under data/ or another explicitly chosen development directory. Save the five files as UTF-8.

    2. Understand the different types

    ConceptThis exampleMeaning
    Package typebrowser moduleManifest has entry and no system/django/locales; there is no manifest kind: journal
    Surfacestable.interface and journal.sheetWhere the module mounts
    Document typediaryNative Journal; the other types are quest, quest_board and roll_table
    Page kindtextNew section contains text; image/pdf pages have different resource needs
    Page audiencegmDraft page is omitted from player projections

    Do not change an existing document's type to fit this example. Quests and roll tables require their own data contracts. The tool explicitly refuses those types.

    3. Package the project

    From the directory containing the five files, run in PowerShell:

    powershell
    python -m json.tool manifest.json
Compress-Archive -LiteralPath manifest.json,main.js,styles.css,messages.json,LICENSE.txt -DestinationPath ../session-journal-1.0.0.zip
python -m zipfile -l ../session-journal-1.0.0.zip

    On Linux/macOS:

    sh
    python3 -m json.tool manifest.json
python3 -m zipfile -c ../session-journal-1.0.0.zip manifest.json main.js styles.css messages.json LICENSE.txt
python3 -m zipfile -l ../session-journal-1.0.0.zip

    The archive listing must show manifest.json at its root beside main.js. This is an unsigned local source package. You can instead review and install the downloadable source ZIP. Do not add an extra outer directory.

    4. Install as owner and activate as GM

    1. As installation owner, open Inside → Modules → Install module → Install from ZIP.

    2. Select session-journal-1.0.0.zip and click Install. Local installation is the owner's explicit trust decision.

    3. Open the campaign as GM. Select the table's Gravewright button → Extensions, then Activate version 1.0.0 of Session notebook. Installation alone does not activate a campaign module.

    4. Close Extensions. The bottom-left panel contains Journal title and Create session journal.

    5. When changing the source later, increment to 1.0.1, build/install a new ZIP and activate that version. Installed releases are immutable; do not edit their extracted files.

    Your first module explains each installation screen.

    5. Create and open a journal from scratch

    1. Keep the default title Session notebook and click Create session journal once. It sends {title, journal_type: "diary", folder_id: null} to create with a fresh operation UUID.

    2. Wait for confirmation. Open Journals at the table and open Session notebook. The host creates an empty private journal at the directory root.

    3. Native creation does not consume a module data field. The next sheet action writes the session draft. Do not invent a create parameter for initial content.

    If creation is not confirmed, inspect Journals before clicking again. Cancellation or a lost response cannot undo a write already committed by the server.

    6. Act on an existing journal

    1. In the opened journal, find the added Session notebook panel. The native editor remains available.

    2. If you were editing, wait for the native Saved indicator first. The public module API does not supply a command to flush another editor's local draft.

    3. Click Add session section. It reads a current server projection, preserves title, visibility, introduction, cover, pages and GM documents, then appends a page.

    4. In the native index, open Sessions → Session notes. It reads: Draft: record the date, discoveries, decisions and loose ends from this session.

    5. The page is GM-only. Edit it using the native editor. To share it, deliberately choose the native Make public option and suitable journal permissions. The module does not automatically publish or present content.

    6. Close/reopen to verify persistence. A second click after the first operation finishes creates another independent page with a fresh ID. Overlapping clicks in one mount are blocked.

    7. Understand writes and conflicts

    journals.update takes journal_id, title, visibility, the integer version read from the server and the complete data object. For diary, data contains content, cover, sections and gm. Do not use the entire projection as data: its field names differ, including content_doc and cover_image. Each page's can_edit is projection metadata and is removed before saving.

    This example writes only from a GM projection because a player's filtered projection is incomplete. The UI checks context.role, and each write separately verifies state.is_gm. The server still checks the authenticated member, campaign, permissions and revision. A player with journal editing rights continues to use the native editor.

    If another window saves between reading and writing, update returns conflict. The module rereads current state, blocks Add and requests Review latest journal. Review native content and resolve local drafts before confirming the review. It never automatically retries or silently replaces version. Each later approved click is a fresh logical operation with a new UUID.

    8. Complete source

    start loads CSS and catalogs through the official translation API. register synchronously declares both surfaces. Every mount owns its state; every read/write receives signal. Closing or deactivating aborts the mount, removes its listeners and disposes its panel. Labels support en, pt-BR and es; original draft titles/text remain unchanged across locales.

    main.js

    javascript
    // Original tutorial. MIT. Target host: Gravewright 0.3.0, SDK 1.x.
const error = key => Object.assign(new Error(key), { tutorialKey: key });
const alive = signal => !signal.aborted;

function elements({ root, signal, onDispose, api }, kind) {
  const el = (tag, text) => {
    const node = root.ownerDocument.createElement(tag);
    if (text !== undefined) node.textContent = text;
    return node;
  };
  const t = (key, params) => api.i18n.t(key, params);
  const panel = el('section');
  panel.className = 'gw-session-tools gw-session-tools--' + kind;
  const heading = el('h3', t('Session notebook'));
  const status = el('p');
  status.setAttribute('role', 'status');
  status.setAttribute('aria-live', 'polite');
  panel.append(heading);
  root.append(panel);
  onDispose(() => panel.remove());
  const report = problem => {
    if (!alive(signal)) return;
    status.textContent = problem.tutorialKey ? t(problem.tutorialKey) :
      t('Request failed: {code}. Review the journal before trying again.', { code: problem.code || 'unavailable' });
  };
  return { el, t, panel, status, report };
}

async function journalSnapshot(api, signal, journalId) {
  const snapshot = await api.journals.state({}, { signal });
  if (!alive(signal)) return null;
  // Only the server's GM projection contains all pages, hidden blocks and GM docs.
  if (snapshot.is_gm !== true) throw error('This tool requires a GM.');
  const view = snapshot.journals.find(row => row.id === journalId);
  if (!view || view.can_open === false) throw error('Journal is unavailable.');
  if (view.type !== 'diary') throw error('This tool only edits Journal documents (diary).');
  if (!view.can_edit) throw error('This journal is read-only.');
  if (!Array.isArray(view.sections) || !view.content_doc || !view.cover_image ||
      !view.diary?.gm?.notes || !view.diary?.gm?.secrets || !Number.isInteger(view.version)) {
    throw error('The complete GM journal projection is unavailable.');
  }
  return view;
}

function appendPayload(view) {
  if (view.sections.length >= 64) throw error('This journal already has 64 pages.');
  const last = Math.max(0, ...view.sections.map(page => Number(page.sortOrder) || 0));
  if (!Number.isSafeInteger(last + 10)) throw error('Page order is outside the supported range.');
  const page = {
    id: 'section_' + crypto.randomUUID().replaceAll('-', '').slice(0, 12),
    title: 'Session notes', category: 'Sessions', kind: 'text',
    assetId: '', src: '', level: 1, audience: 'gm', sortOrder: last + 10,
    content: { format: 'gw-journal-doc-v1', version: 1, doc: { type: 'doc', content: [
      { type: 'paragraph', attrs: { visibility: 'public' }, content: [
        { type: 'text', text: 'Draft: record the date, discoveries, decisions and loose ends from this session.' }
      ] }
    ] } }
  };
  const sections = view.sections.map(({ can_edit, ...section }) => structuredClone(section));
  return {
    journal_id: view.id, title: view.title, visibility: view.visibility, version: view.version,
    data: {
      content: structuredClone(view.content_doc), cover: structuredClone(view.cover_image),
      sections: [...sections, page], gm: structuredClone(view.diary.gm)
    }
  };
}

async function mountCreate(block) {
  const { context, api, signal } = block;
  if (context.role !== 'gm' || !alive(signal)) return;
  const { el, t, panel, status, report } = elements(block, 'table');
  const form = el('form');
  const label = el('label', t('Journal title'));
  const input = el('input');
  input.type = 'text'; input.required = true; input.maxLength = 120;
  input.value = 'Session notebook';
  const create = el('button', t('Create session journal'));
  create.type = 'submit';
  label.append(input); form.append(label, create); panel.append(form, status);
  let busy = false;
  form.addEventListener('submit', async event => {
    event.preventDefault();
    if (busy || !alive(signal)) return;
    const title = input.value.trim();
    if (!title || title.length > 120) { report(error('Enter a title from 1 to 120 characters.')); return; }
    busy = true; create.disabled = true; input.disabled = true;
    status.textContent = t('Creating journal...');
    try {
      const snapshot = await api.journals.state({}, { signal });
      if (!alive(signal)) return;
      if (snapshot.is_gm !== true) throw error('This tool requires a GM.');
      const result = await api.journals.create({ title, journal_type: 'diary', folder_id: null },
        { requestId: crypto.randomUUID(), signal });
      if (!alive(signal)) return;
      status.textContent = t('Created "{title}". Open it in Journals, then add a session section.', { title });
      status.dataset.journalId = result.journal_id;
    } catch (problem) { report(problem); }
    finally { if (alive(signal)) { busy = false; create.disabled = false; input.disabled = false; } }
  }, { signal });
}

async function mountAppend(block) {
  const { context, api, signal } = block;
  if (context.role !== 'gm' || !alive(signal)) return;
  const { el, t, panel, status, report } = elements(block, 'journal');
  const add = el('button', t('Add session section'));
  const review = el('button', t('Review latest journal'));
  add.type = review.type = 'button';
  add.disabled = review.disabled = true;
  const hint = el('p', t('Save pending native edits first. New session drafts are GM-only.'));
  panel.append(hint, add, review, status);
  let busy = false, ready = false, needsReview = false;
  const controls = () => {
    if (!alive(signal)) return;
    add.disabled = busy || !ready || needsReview;
    review.disabled = busy;
  };
  async function refresh() {
    if (busy || !alive(signal)) return;
    busy = true; ready = false; controls();
    try {
      const view = await journalSnapshot(api, signal, context.journalId);
      if (!view || !alive(signal)) return;
      ready = view.sections.length < 64;
      needsReview = false;
      status.textContent = t('Latest saved version: {version}. Pages: {count}.', { version: view.version, count: view.sections.length });
      if (!ready) report(error('This journal already has 64 pages.'));
    } catch (problem) { report(problem); }
    finally { if (alive(signal)) { busy = false; controls(); } }
  }
  review.addEventListener('click', () => void refresh(), { signal });
  add.addEventListener('click', async () => {
    if (busy || !ready || needsReview || !alive(signal)) return;
    busy = true; controls();
    status.textContent = t('Saving session section...');
    try {
      const view = await journalSnapshot(api, signal, context.journalId);
      if (!view || !alive(signal)) return;
      const payload = appendPayload(view);
      await api.journals.update(payload, { requestId: crypto.randomUUID(), signal });
      if (!alive(signal)) return;
      ready = payload.data.sections.length < 64;
      status.textContent = t('Added GM-only "Session notes". Open it under Sessions in the native journal.');
    } catch (problem) {
      if (!alive(signal)) return;
      needsReview = true;
      if (problem.code === 'conflict') {
        try {
          const latest = await journalSnapshot(api, signal, context.journalId);
          if (!latest || !alive(signal)) return;
          ready = latest.sections.length < 64;
          status.textContent = t('Conflict: server version {version} loaded. Review native content, then choose Review latest journal. No automatic retry.', { version: latest.version });
        } catch (refreshProblem) { ready = false; report(refreshProblem); }
      } else report(problem);
    } finally { if (alive(signal)) { busy = false; controls(); } }
  }, { signal });
  await refresh();
}

export default {
  async start({ api, assets, styles, signal }) {
    styles.use('styles.css');
    const messages = await assets.json('messages.json');
    if (!alive(signal)) return;
    api.i18n.register(messages);
  },
  register({ register }) {
    register('table.interface', { mode: 'augment', mount: mountCreate });
    register('journal.sheet', { mode: 'augment', mount: mountAppend });
  },
  stop() {}
};

    9. Validate before adapting

    CaseProcedureExpected result
    Basic writeCreate, open, add, reopenOne persisted GM page containing the original draft
    Existing contentUse a cover, introduction, public page, GM page and GM notes/secretsExisting fields survive unchanged; exactly one page is appended
