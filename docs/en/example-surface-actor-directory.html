    actor.directory: Readable actor counter

    Count actors whose sheets the current member may open, and update after actor changes.

    What you will build

    Count actors whose sheets the current member may open, and update after actor changes.

    Surface: actor.directory · Mode: augment · Gravewright 0.3.0 / SDK 1.x.

    When it mounts and who can use it

    Open the Actors directory. No document ID is needed: the mount is already bound to its table and member.

    The owner installs the local ZIP under Modules → Install module → Install from ZIP. The GM then activates the exact version in the table extension list. This example requests no extra permissions or global handle; all reads use the mount’s supplied api. GMs and players receive only server-authorized data. Streamers do not receive this authenticated mount.

    Download the complete package

    Download source ZIP · manifest.json · main.mjs · styles.css · LICENSE.txt

    Save all four files in the same folder. ZIP the folder contents, with manifest.json directly at the archive root. Do not include a wrapper folder, local state or private keys. Local upload is the owner’s trust decision; for catalog distribution, use the signing workflow in the module reference.

    main.mjs

    javascript
    // Original documentation example. License: MIT. Target: Gravewright 0.3.0, SDK 1.x.
export default {
  start({ api, styles }) {
    styles.use("styles.css");
    api.i18n.register({
      "en": {
        "Readable actors: {count}": "Readable actors: {count}",
        "Refresh": "Refresh",
        "Loading…": "Loading…",
        "Error: {code}": "Error: {code}",
        "Readable actor counter": "Readable actor counter"
      },
      "pt-BR": {
        "Readable actors: {count}": "Atores legíveis: {count}",
        "Refresh": "Atualizar",
        "Loading…": "Carregando…",
        "Error: {code}": "Erro: {code}",
        "Readable actor counter": "Contador de atores legíveis"
      }
    });
  },
  register({ register }) {
    register("actor.directory", { mode: "augment", mount: this.mount });
  },
  async mount({ root, context, api, storage, viewport, events, signal, onDispose }) {
    const el = (tag, text) => {
      const node = root.ownerDocument.createElement(tag);
      if (text !== undefined) node.textContent = text;
      return node;
    };
    const t = (key, params) => api.i18n.t(key, params);
    const panel = el("section"); panel.className = "gw-example";
    const heading = el("h3", t("Readable actor counter"));
    const output = el("pre"); output.setAttribute("role", "status");
    panel.append(heading, output); root.append(panel);
    onDispose(() => panel.remove());
    const report = error => {
      if (!signal.aborted) output.textContent = t("Error: {code}", { code: error.code ?? "unavailable" });
    };
    let ticket = 0;
    const refresh = async () => {
      const current = ++ticket;
      try {
        const value = await api.actors.list({}, { signal });
        if (signal.aborted || current !== ticket) return;
        output.textContent = t("Readable actors: {count}", { count: value.filter(actor => actor.canOpen).length });
      } catch (error) { if (current === ticket) report(error); }
    };
    const refreshButton = el("button", t("Refresh")); refreshButton.type = "button";
    panel.append(refreshButton);
    refreshButton.addEventListener("click", () => void refresh(), { signal });
    onDispose(api.events.on("actors.changed", () => void refresh()));

    await refresh();
  },
  stop() {
    // Mount and module lifetimes already dispose styles, catalogs and subscriptions.
  }
};

    Expected result and cleanup

    Count actors whose sheets the current member may open, and update after actor changes.

    The native interface remains usable. Closing a sheet, switching scenes, leaving the table or deactivating the module aborts the mount. Listeners use signal; events and owned elements are released through onDispose. Async reads check cancellation and discard old responses before rendering. Errors are displayed through error.code, including network failures.

    Validate on a disposable table

    1. Create an actor, revoke a player’s read access, and check that the count follows the authorized collection.

    2. Open/close three times, then deactivate while a read or modal is pending. Check that no old panel or error appears after disposal.

    3. Test empty state, long document names, keyboard navigation and a narrow viewport. Compare GM and player accounts.

    4. Check the browser console. These source examples have runtime contract tests; installation and visual behavior still require validation on the target host.
