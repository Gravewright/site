What is Gravewright?

Everything you need to bring an RPG table online, without turning setup into the game.

Gravewright is a browser-based virtual tabletop for groups that want maps, characters, combat, atmosphere, and campaign tools in one place. It is open source, self-hostable, and designed so different RPG systems can feel like themselves instead of being forced into the same rules.

Explore the map

Build scenes with walls, doors, fog, dynamic vision, lighting, measurements, pings, and token movement.

Run the characters

Use actors, items, character sheets, fillable PDFs, resources, conditions, chat, dice, and combat tools.

Set the mood

Add rain, snow, smoke, embers, magic, animated lighting, and cinematic effects directly to your scenes.

Keep control

Manage players, permissions, join codes, snapshots, backups, streamer views, and the data behind your campaigns.

Run it locally

Gravewright runs on your own machine and opens in the browser.

If you prefer to run directly from the source repository, the setup is still short. The release page is the easier starting point for most people.

For source installs Python 3.11 or newer uv
Source setup 
git clone https://github.com/Gravewright/gravewright.git
cd gravewright
cp .env.example .env
uv sync
chmod +x grave
./grave doctor
./grave run --open
Then open: http://127.0.0.1:8000

Windows PowerShell

The same source setup is available on Windows using the included Gravewright launcher.

Windows source setup 
git clone https://github.com/Gravewright/gravewright.git
cd gravewright
Copy-Item .env.example .env
uv sync
.\grave.bat doctor
.\grave.bat run --open
Need help? See the documentation linked above.

Alpha 3

A much more complete tabletop.

Version 3 brings together scene building, visibility, movement, visual effects, combat, cards, campaign management, and system support into a more complete play experience.

Classic or Cinematic

Each player can choose a lighter Classic view or a richer Cinematic presentation without changing the game for everyone else.

Walls that matter

Walls and doors now work across vision, lighting, visual effects, and player movement for more consistent scenes.

More atmosphere

Use particles, weather, animated lighting, and a library of 50 scene effect presets to give maps their own identity.

Better campaign tools

Join codes, ready checks, snapshots, campaign cloning, search, and admin history make running the table easier.

For Players and Game Masters

Gravewright is built to feel like a tabletop first. Create a scene, invite the group, move tokens, reveal the map, roll dice, use cards, track combat, and keep the session moving.

  • maps, walls, doors, fog, and lighting
  • tokens, sheets, PDFs, items, and resources
  • chat, dice, cards, and combat
  • particles, weather, and cinematic effects
  • permissions, streamer views, and campaign tools

For RPG System Creators

Want Gravewright to understand your game? Ruleset packages can define the sheets, rolls, resources, conditions, combat behavior, initiative, and presentation that make your system unique.

  • custom actor and item types
  • game-specific sheets and rolls
  • derived values and conditions
  • custom combat and initiative
  • localization and starter content

Project Status

Gravewright is currently v3.0.2-alpha.

Alpha 3 already includes the main pieces expected from a general-purpose VTT: scenes, maps, dynamic vision, lighting, walls and doors, tokens, sheets, PDFs, combat, cards, chat, effects, permissions, campaign tools, and an extensible ruleset system.

The next stage is less about proving how many features Gravewright can have and more about making the whole experience dependable, polished, and easier to use.

Alpha software can still change. Keep backups of important campaign data.
