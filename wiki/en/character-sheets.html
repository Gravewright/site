    Character sheets and the PDF system

    Use an existing character PDF or the sheet supplied by an installed RPG system.

    Choose the right sheet

    The included Gravewright PDF System lets a campaign use PDF character sheets without making the host depend on a particular RPG. Installed systems can instead provide their own fields, resources, item types, translations and automation. A sheet shown for an optional system is not a promise that its rules are built into the core.

    Prepare a PDF character

    1. Create or open an actor in a campaign using the PDF system.

    2. Upload a character-sheet PDF you are authorized to use.

    3. Open the sheet's PDF editing/mapping controls and configure the fields needed by your group.

    4. Enter a few sample values, save and reopen to confirm persistence before filling the entire character.

    5. Grant the intended player ownership and verify the sheet from that player's session.

    6. If you reuse the layout, verify it on another character before investing in a larger collection.

    Mapping fields onto a PDF does not import a rulebook or implement all calculations from an RPG. Agree with your group on which values you maintain manually and which an installed system actually automates.

    Map a PDF without editable fields

    As GM, choose Map fields, then text, number, checkbox or multiline text. Drag a rectangle onto the page or choose Add field, name it and adjust its bounds. Drag moves it; its lower-right handle resizes it. Arrow keys move one displayed pixel and Shift moves ten. Choose Finish mapping to fill values. Native PDF widgets and manual overlays use the same authorized sheet values; the source PDF is unchanged, and there is no OCR step.

    Double-click a native or manual field, or press F2 while it is focused, to configure Field actions. Bind a value to a token bar or choose a saved dice action. Six presets include d20, highest/lowest of two d20s, 2d6, exploding d6 and 4dF. 1d20 + @value reads this field; 1d20 + @{field-key} reads another numeric field. Use Reference field for exact keys. Authorized editors run saved actions with the roll button or Alt+Enter; a GM double-click opens configuration. Dice permissions and normal visibility still apply.

    Use the authoring and reuse tools

    CapabilityWhat to check
    Calculated fieldsArithmetic and field references recompute on save; cycles are rejected and calculated values are read-only
    Layout editingMultiple selection, copy/paste, duplicate, alignment, distribution and optional snapping apply to the active layout
    Undo and redoUp to 50 local layout steps preserve current character values; changing the PDF clears this history
    Mapping JSONTransfer layout definitions, bindings, actions and calculations without PDF bytes or character values
    Mapping librarySave a reusable campaign template and apply it to the same PDF layout, with field identities preserved
    Batch applicationApply to selected permitted actors; all target revisions are validated before committing
    Diagnostics and filled PDFInspect missing fields/references and layout mismatches; export a separate flattened PDF with current values

    These tools complement manual mapping and saved actions; they do not automatically supply RPG rules. Filled export is bounded and fails on overflow instead of silently returning an incomplete document. See the PDF System reference for limits and formulas.

    Edit the intended source

    Opening a sheet from a linked token uses actor data; an independent snapshot token uses its own copy. Check this before changing health, notes or other resources on duplicate creatures. A missing portrait or PDF may be an asset-access issue rather than a missing actor.

    Recover from a save conflict

    If another session changed the sheet, reload the current state and reapply the intended edit. Do not repeatedly force an old form over a newer revision. If a save response is uncertain after connection loss, inspect the reopened sheet before entering the same change again.

    Content and limits

    The native PDF system does not include item types or a proprietary catalog. PDFs and images retain their own licenses; owning a book does not automatically authorize redistributing it in public downloads. Keep licensed personal material in the private campaign storage and share only within your authorization.
