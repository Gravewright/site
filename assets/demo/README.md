# Demo media sources / Fontes das mídias de demonstração

The two site screenshots were captured from the real Gravewright Alpha 0.1.0 interface in Chromium, using an isolated local database and fictional sample campaigns. The live campaigns were not edited. The screenshots are 1600 × 1000 WebP captures.

- `../images/pdf-character-sheet.webp`: Seren Ashford's editable PDF sheet, health 28, energy 12, defense 16, attributes, abilities, equipment and notes.
- `../images/campaign-dashboard.webp`: three fictional campaigns, sample account and participants.
- `Seren-Ashford.pdf`: original editable PDF layout with seven form fields. Values in the screenshot are stored in the demo character; the standalone PDF fields start blank.
- `verdant-vigil.png`: new forest abbey campaign illustration.
- `drowned-crown.png`: new ocean palace campaign illustration.

All three campaign illustrations were created with the built-in image generation tool in text-to-image mode. The application interface was captured in the browser, not generated. `ashfall-citadel.png` is the volcanic fortress cover for Ashfall Citadel. The PDF layout and fictional character text were authored for this demonstration and follow the site's first-party license.

As duas capturas mostram a interface real do Gravewright Alpha 0.1.0, com campanhas fictícias em uma base local isolada. As campanhas originais não foram editadas. As artes da abadia, do palácio marítimo e da fortaleza vulcânica foram geradas para esta demonstração; a ficha PDF também é original. No PDF avulso, os campos começam vazios; os valores da captura pertencem ao personagem de demonstração.
