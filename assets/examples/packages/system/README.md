# Example Expedition

Create a campaign using Example Expedition. The package declares character and npc actors, an empty gear item type, and replaces the actor sheet with an editable stamina field. It provides no published game rules or catalogs.

Crie uma campanha com Example Expedition. O pacote declara atores character e npc, um tipo vazio de item gear e substitui a ficha por um campo de vigor editável. Não inclui regras publicadas nem catálogos.

Target host: Gravewright 0.3.0; SDK 1.0.0.
Unsigned sources: review, then use Install from ZIP on a disposable host. Marketplace publication requires the documented publisher signature.
Fontes sem assinatura: revise e use Instalar de ZIP em host descartável. Publicação no Marketplace requer a assinatura documentada do publicador.
