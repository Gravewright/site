# Example server status

Expose GET /examples/status/ for the authenticated installation owner. It returns the public Python API version and no campaign content. This is an independent generic server integration, not a companion for an RPG system.

Disponibilize GET /examples/status/ ao proprietário autenticado da instalação. A resposta contém a versão pública da API Python e nenhum dado de campanha. É uma integração genérica independente, sem função de complemento de sistema de RPG.

Target host: Gravewright 0.3.0; SDK 1.0.0.
Unsigned sources: review, then use Install from ZIP on a disposable host. Marketplace publication requires the documented publisher signature.
Fontes sem assinatura: revise e use Instalar de ZIP em host descartável. Publicação no Marketplace requer a assinatura documentada do publicador.
