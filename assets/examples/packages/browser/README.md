# Example campaign summary

Add a Campaign summary button to table.interface. Clicking it reads only the actors visible to the signed-in user and opens the result in the existing modal component.

Adicione o botão Campaign summary em table.interface. Ao clicar, ele lê somente os atores visíveis ao usuário conectado e mostra o resultado no modal existente.

Target host: Gravewright 0.3.0; SDK 1.0.0.
Unsigned sources: review, then use Install from ZIP on a disposable host. Marketplace publication requires the documented publisher signature.
