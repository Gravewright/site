# Example language demo

Ship a deliberately partial catalog for six original interface strings in pt-BR and es. This demonstrates package structure and fallback; it is not a complete translation or a replacement release of the official Translator.

Distribua um catálogo propositalmente parcial de seis textos de interface em pt-BR e es. Ele demonstra estrutura e alternativa de idioma; não é tradução completa nem nova release do Translator oficial.

Target host: Gravewright 0.3.0; SDK 1.0.0.
Unsigned sources: review, then use Install from ZIP on a disposable host. Marketplace publication requires the documented publisher signature.
Fontes sem assinatura: revise e use Instalar de ZIP em host descartável. Publicação no Marketplace requer a assinatura documentada do publicador.

Documentation: https://gravewright.com/docs/en/example-package-language.html
Português: https://gravewright.com/docs/pt-BR/example-package-language.html
