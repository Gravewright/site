# Practical tutorial captures / Capturas dos tutoriais práticos

Real browser screenshots from Gravewright 0.3.0, source revision
23ea61b8efb566cad0e3359489b0dad45e214906, captured on 20 October 2026.
1440 × 1000, English interface; captions and alternative text are EN/PT.

The public tutorial ZIPs were installed with ModulePackages.install_local
in newly created, installation-local SQLite/media/module fixtures.
Each workbench screenshot follows an actual click on Run action and the
specified recipe. Empty collections show the initial authorized state.
The asset screenshot follows a real multipart upload of an original solid
color portrait. The original SDK screenshot precedes a separately verified
create/read/update/data/delete lifecycle and independent-token data edit.
The journal, sheet, compendium and Customize screenshots follow native
browser actions that saved and reread the resulting documents/preferences.

All campaigns, accounts, document identifiers, notes and scene artwork are
owned synthetic examples. The background is an original grid. No operator
configuration, credentials, database, private media or proprietary catalog
was used. Images were captured directly by Chromium/Playwright without
image generation or compositing. Only public screenshots are copied here;
private test scripts, reports, database files and browser sessions stay out
of the site and ZIP downloads.

Capturas reais dos módulos instalados e executados na aplicação, em fixtures
novas e descartáveis. Grade e conteúdo originais sintéticos, interface em
inglês, legendas EN/PT. As capturas de leitura podem mostrar coleções vazias;
isso documenta o estado inicial, sem sugerir que dados foram criados.
Nenhuma imagem é mockup e nenhuma credencial ou dado de campanha privada
foi publicado.
